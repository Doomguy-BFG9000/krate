# Good first issues

First tasks for new contributors live on GitHub, labeled
[`good first issue`](https://github.com/incyashraj/krate/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22).
Each one names the files to change, what done looks like, and the command
that proves it.

To start: comment on the issue to say you are taking it, then follow
[CONTRIBUTING.md](../../CONTRIBUTING.md) for setup and the checks every pull
request runs.
